AMI Training
Overview
   This repository contains the programs, practice exercises, assignments, and learning materials completed during my **System Software Engineer Training at American Megatrends International (AMI)**.
   The training focused on strengthening my programming fundamentals and understanding of **system software, Linux, firmware, BIOS, and OpenBMC technologies**.

Training Objectives
* Strengthen programming fundamentals using C 
* Develop problem-solving and logical thinking skills
* Learn Linux operating system concepts and commands
* Understand system software and firmware development
* Gain foundational knowledge of BIOS
* Explore OpenBMC and its architecture
* Practice Git and GitHub for version control and project management
